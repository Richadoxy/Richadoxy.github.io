# Xiyue Dong — Personal Homepage

A lightweight bilingual academic homepage inspired by the information architecture of Academic Pages. It is plain HTML, CSS, and JavaScript, so it can be hosted directly on GitHub Pages without a build step.

## Preview locally

From this directory, run:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Information intentionally left blank

- Google Scholar profile
- CV file
- Paper, code, video, and project-page links
- Project demos and research notes

Search for `placeholder`, `pending`, `TBD`, or `待补充` in `index.html` to find the main unfinished fields.

## Deploy to GitHub Pages

1. Create a repository named `Richadoxy.github.io`.
2. Copy the contents of this directory to the repository root.
3. Push to the default branch.
4. In GitHub repository settings, enable Pages deployment from the default branch and root directory.

No Ruby, Jekyll, Node.js, or database is required.

## Rebuild the Learning Journey blog

The generated blog lives in `blog/`. Its Markdown sources and Draw.io files are copied from the BrainCo-IL documentation directory so the published site remains self-contained.

```bash
python3 -m venv .blog-build-env
.blog-build-env/bin/pip install Markdown==3.8.2
.blog-build-env/bin/python scripts/build_blog.py
```

The script rebuilds the learning-path article pages from the bundled Markdown in `blog/source/`. The bundled files are the canonical website sources, so a normal build never overwrites local edits.

To explicitly refresh matching engineering notes and Draw.io diagrams from the external BrainCo documentation directory, opt in with:

```bash
.blog-build-env/bin/python scripts/build_blog.py --sync-upstream
```

The archive is organized into seven dependency-first series: foundations, imitation learning, VLA architectures, engineering, runtime/deployment, tactile VLA, and reinforcement learning for dexterous manipulation. Article codes such as `F01`, `IL01`, `VLA01`, and `RL01` express the reading path while legacy foundation URLs redirect to their consolidated replacements.

The PI0.5 path separates forward architecture (`VLA02`) from FAST/KI training and fine-tuning (`VLA03`), then connects to the engineering notes. Official openpi code references in the training article are pinned to a commit; BrainCo-IL-specific configuration examples remain identified as project extensions.

The RL path starts with a research map (RL01), develops actor–critic networks, returns, GAE, PPO, and goal conditioning (RL02), then explains teacher–student transfer, DAgger, and deployment (RL03). Beginner bridges distinguish network roles from MLP/LSTM structure, and privileged training information from estimated deployment observations. HORA (RL04), UniDexGrasp (RL06), SimToolReal (RL07), AdaDexTrack (RL08), and ADEPT (RL09) provide paper walkthroughs; the experiment-reading guide (RL05) can be read before these papers. Each walkthrough specifies training and deployment observation fields, dimensions, and sources, with a cross-paper comparison in RL03.

SimToolReal follows the supplied arXiv v2 in nine sections: task abstraction, training and video use, networks, observations, perception, generalization, contributions, experiments, and review questions. Two diagrams support the main explanation; three additional diagrams cover keypoints, rewards, and experimental evidence. Code references are pinned separately from the paper version. The new visual-state-estimation primer (F05) introduces 6D poses, RGB-D, meshes, calibration, and FoundationPose, with a separate pipeline diagram. Both the foundation and RL reading maps link to this prerequisite. Canonical sources include `49_simtoolreal_paper_walkthrough.md` and `50_visual_state_estimation_and_foundationpose.md` in `blog/source/`.

AdaDexTrack follows the supplied arXiv v1, distinguishing reference states from expert action labels, PPO specialists from the distilled BC tracker, and the frozen tracker from its RL modulator. The article covers reference generation, expert counts for each evaluation split, the shared 273-dimensional observation format, domain randomization, real deployment, and the limits of the ablation evidence. Its canonical source is `51_adadextrack_paper_walkthrough.md`; the pipeline diagram is generated by `scripts/build_adadextrack_figures.py`.

ADEPT follows Fig. 2 of the supplied PDF: PPO pretraining, BC transfer to the downstream actor, frozen-actor critic warm-up, conservative PPO, perceptive student distillation, and deployment. It specifies what learns at each stage, the student architecture, and the observation interfaces of both robot embodiments. Controller state remains listed as an observation field; Fabric internals are outside this walkthrough. The source is `52_adept_paper_walkthrough.md`, with training and student-network diagrams generated by `scripts/build_adept_figures.py`.

Regenerate the RL diagrams before rebuilding the blog:

```bash
python3 scripts/build_rl_figures.py
python3 scripts/build_unidexgrasp_figures.py
python3 scripts/build_simtoolreal_figures.py
python3 scripts/build_adadextrack_figures.py
python3 scripts/build_adept_figures.py
.blog-build-env/bin/python scripts/build_blog.py
```
