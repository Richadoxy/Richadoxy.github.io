动作生成方法：从连续回归到概率生成

进阶 · September 2026 · 17 min read进阶 · 2026.09 · 约 17 分钟阅读

串联回归、自回归、CVAE、GAN、扩散、Flow Matching 与生成一致性，区分训练目标、采样和执行。

动作生成可以看成一件很具体的事：把当前看到、摸到和记住的信息，转换成接下来要执行的命令。不同方法的区别，在于它们怎样表示多个可能的动作，以及怎样从这些可能性中生成一条动作序列。

本文先建立统一地图，再连接 DP 与 ACT、Flow Matching 和 生成一致性与采样蒸馏。第 8 节补充 Glow 所属的 Normalizing Flow，并区分动作生成、抓姿分布与测试时优化；具体两阶段实例见 UniDexGrasp 精读。网络的连接方式可以配合 从对齐表示到 Policy 融合 阅读。

1. 数据相同，训练问题可以不同

设一次训练样本包含条件 \(c\) 和专家动作块 \(A\)：

\[ c=(\text{图像、触觉、本体状态、任务目标、允许的历史}), \qquad A\in\mathbb R^{H\times D_a}. \]

\(H\) 是预测多少个未来控制步，\(D_a\) 是每步命令的维数。加入 batch 维以后，动作张量是 \([B,H,D_a]\)。

这些数据既可以训练直接回归，也可以训练自回归、CVAE、扩散或 flow。训练方法会在已有样本上进一步构造 token、潜变量、噪声级或带噪动作，所以数据集里不必预先保存这些派生监督量。

同一份 observation + 专家动作
       ├─ 直接比较预测动作与专家动作
       ├─ 将动作编码为 token，预测 token 的条件分布
       ├─ 通过潜变量编码不同的动作模式
       └─ 给动作加噪，学习把噪声分布变成动作分布

condition 是“生成动作时可参考的信息”。它可以是一个向量、一组 token，或者若干调制参数；condition 不是一种专门的数据格式。

2. 连续回归与多种合理动作

最直接的方法是让网络一次输出整个动作块：

\[ \hat A=f_\theta(c),\qquad \mathcal L_{\mathrm{reg}}= \mathbb E_{(c,A)\sim\mathcal D}\left[\|f_\theta(c)-A\|_2^2\right]. \]

公式中的期望表示在数据分布上取平均。代码通常用 minibatch 的均值近似它，实际还要对动作维度和有效时间步做归一化与 mask。

当 \(c\) 下只有一种主要的合理动作时，这种方法简单有效。但如果同一个障碍物可以从左右两边绕过，训练数据就可能包含两种路线。确定性 MSE 回归的理想解是条件均值，两条路线的平均可能穿过障碍物。

这说明动作预测还涉及分布中的多个模式。“多峰动作分布”与“多模态传感器”是两个不同含义：前者指多个合理答案，后者指视觉、触觉等不同输入来源。

L1 回归偏向条件中位数，但也不会自动产生完整的多峰分布。增加潜变量，或者直接学习分布，才能明确引入不同的生成结果。

3. 自回归：按顺序生成表示元素

自回归把一个联合分布拆成一串条件分布：

\[ p_\theta(y_{1:N}\mid c) =\prod_{j=1}^{N}p_\theta(y_j\mid y_{<j},c). \]

\(y_j\) 是序列里的第 \(j\) 个元素。对于离散动作生成，它通常是动作 tokenizer 产生的 token。一个 token 可以表示某个关节的量化值，也可以表示一段经过压缩的动作，因此 token 序号不一定对应机器人的物理时间。

训练时常用 teacher forcing：把正确的历史 token 作为输入，预测下一个 token 的概率分布。

\[ \mathcal L_{\mathrm{AR}} =-\mathbb E_{(c,y^*)\sim\mathcal D} \sum_{j=1}^{N} \log p_\theta(y_j^*\mid y_{<j}^*,c). \]

这就是 token 交叉熵。模型输出的是词表上各类别的分数，损失关注正确类别的概率；不能把 token ID 当连续数值，直接计算“预测编号减真实编号”。

训练：正确的前缀 → 同时计算各位置的下一 token 预测 → 交叉熵
推理：已生成前缀 → 下一个 token → 更新前缀 → 继续生成

因果 attention mask 允许训练时并行计算这些位置，但普通自回归推理仍有前后依赖。Transformer 本身不等于自回归：它也可以一次处理整段带噪动作。连续变量也能按条件分布逐个生成，此时通常使用连续分布的负对数似然。

RT-2 是将动作编码为 token 并接入视觉语言模型的一个具体例子。RT-2 原论文

FAST 则先对动作块的每个维度沿时间轴做 DCT，再量化频域系数、按低频优先排列，最后用 BPE 合并常见的系数组合。它压缩的是整段动作的表示：token 顺序对应压缩后的编码顺序，不能把“预测下一个 token”理解为“预测下一个机器人控制时刻”。量化引入近似误差，BPE 对量化后的符号序列做无损合并。FAST 原论文

4. VAE / CVAE：用潜变量组织动作模式

先从拿杯子的例子理解：相同起始场景下，示范者可能缓慢接近，也可能较快接近。普通确定性预测只接收观测 \(c\)，而 CVAE 给动作生成器增加一个潜变量输入 \(z\)，用它容纳观测未完全解释的动作差异：

\[ \hat A=f_\theta(c) \quad\longrightarrow\quad \hat A=f_\theta(c,z). \]

数据集没有给每条示范标注 \(z\)，所以训练时需要一个编码器，根据专家动作推断它可能对应哪些潜变量。这个编码器与动作生成器联合训练。潜变量是一次前向中的向量，网络权重则是训练中积累下来的参数，两者不能混淆。

CVAE 是条件变分自编码器：条件指观测信息，变分指用可训练分布近似真实后验，自编码器指训练时先编码示范、再尝试重建它。VAE/CVAE 的输入可以是图像、动作或触觉；ViT 则是一种网络结构。VAE 原论文

先把三个分布读成三个问题，再看损失：

分布 在问什么 实际作用
先验 \(p(z\mid c)\) 还没看到这条具体动作，\(z\) 可能是什么 提供生成时的潜变量来源；也可以简化成不依赖条件的标准高斯
近似后验 \(q_\phi(z\mid A,c)\) 已经看到示范动作，哪些 \(z\) 能解释它 编码器输出分布参数，再采样得到 \(z\)
生成分布 \(p_\theta(A\mid z,c)\) 给定场景与 \(z\)，能生成什么动作 解码器，即动作生成网络

“先验／后验”的先后相对于是否已知这条示范，不是训练之前与之后。下面是一般 CVAE 的完整条件写法；原始 ACT 的近似后验为了效率，只读取动作和关节状态，省略图像。

训练时，decoder 根据潜变量和条件重建动作。常见目标是：

\[ \mathcal L_{\mathrm{CVAE}} =\mathbb E_{z\sim q_\phi(z\mid A,c)} [-\log p_\theta(A\mid z,c)] +\beta D_{\mathrm{KL}} \big(q_\phi(z\mid A,c)\|p(z\mid c)\big). \]

第一项比较生成动作与专家动作。第二项中的 KL 散度比较两个潜变量分布，对后验偏离先验的程度施加代价，防止编码器任意使用部署时难以获得的示范专属代码。它不直接比较动作，也不要求每个 \(z\) 等于零。

\(\beta\) 控制两项的取舍：既要保留帮助重建的示范信息，也要限制后验的偏离程度。\(\beta=1\) 对应标准负 ELBO（证据下界取负）的形式。具体高斯分布的 KL 数值例子见 ACT 的先验、后验与 KL。

重建损失取决于输出分布假设：固定方差高斯对应缩放后的 MSE，固定尺度 Laplace 对应缩放后的 L1。不同 VAE 不必使用同一种重建损失。

训练：专家动作 A + 条件 → 后验 encoder → 采样 z ─┐
                                               ├→ decoder → 重建 A
                              观测条件 c ──────┘

生成：                     从先验选择 z ────────┐
                                               ├→ decoder → 生成 A
                              观测条件 c ──────┘

推理时没有未来专家动作，因此跳过依赖它的训练后验。一般 CVAE 可以从先验采样来生成不同结果；原版 ACT 固定使用 \(z=0\)，即标准高斯先验的均值，一次前向输出动作块。这只是固定了一个输入，训练好的动作策略权重、图像和状态输入都仍然保留。KL 有助于训练与部署的衔接，但不保证零向量总是最优选择。ACT 原论文

训练时潜变量让模型有机会区分示范方式；固定 \(z\) 部署后，同一观测下的策略输出仍然是确定性的。后验编码器如何更新、重参数化如何传梯度，以及与 DP 的区别，在 DP 与 ACT 中展开。

5. GAN：让判别器提供生成反馈

GAN 使用两个网络：生成器 \(G\) 根据条件和随机变量产生样本，判别器 \(D\) 学习区分真实样本与生成样本。生成器通过判别器的反馈改善输出。这种对抗训练是 GAN 原论文 的基本思路；下面把它写成条件动作生成的形式。

\[ \hat A=G_\theta(z,c),\qquad z\sim p(z). \]

常见的判别器损失和非饱和生成器损失分别是：

\[ \mathcal L_D =-\mathbb E_{(A,c)\sim\mathcal D}\log D_\psi(A,c) -\mathbb E_{c,z}\log\big(1-D_\psi(G_\theta(z,c),c)\big), \]

\[ \mathcal L_G =-\mathbb E_{c,z}\log D_\psi(G_\theta(z,c),c). \]

训练判别器时把生成样本视为固定输入；训练生成器时保留经过判别器的梯度，但只更新生成器参数。推理通常只保留生成器。上述公式只是一种 GAN 配方，不能直接套到 WGAN 等变体。

GAN 的训练需要处理两套网络之间的平衡，也可能遗漏部分数据模式。这里介绍它是为了补齐生成学习的地图，不能据此推断某个 VLA 已使用 GAN，也不能把一个预测操作成功率的 classifier 自动称为 GAN 判别器。

6. Diffusion：学习带噪动作的恢复方向

用 \(k\) 表示离散扩散步，给专家动作加上自己采样的噪声：

\[ A^k=\sqrt{\bar\alpha_k}A^0 +\sqrt{1-\bar\alpha_k}\epsilon, \qquad \epsilon\sim\mathcal N(0,I). \]

由于噪声是程序采样出来的，它的数值完全已知。典型噪声预测损失是：

\[ \mathcal L_\epsilon =\mathbb E_{(c,A^0),k,\epsilon} \left[\|\epsilon_\theta(A^k,k,c)-\epsilon\|_2^2\right]. \]

模型预测噪声以后，就能从带噪动作中减去相应成分，并交给采样器继续更新。“监督噪声”和“完成去噪”在这条链路里是相连的。DDPM 原论文

真实动作在训练中用于构造 \(A^k\)，推理则从随机噪声开始。模型每次读取当前带噪动作、噪声阶段和观测条件，逐步得到动作块。整个动作块可以并行去噪，不必按机器人时间逐步自回归。

扩散也可以直接预测干净动作 \(A^0\)。这种 \(x_0\)-prediction 仍然读取带噪输入和噪声级，并不等于只根据 observation 做一次确定性 BC 回归。不同参数化之间的关系见 Flow Matching 与目标参数化。

7. Flow Matching：学习生成路径上的速度

以噪声到动作的线性路径为例：

\[ x_s=(1-s)\epsilon+sA,\qquad u_s=A-\epsilon,\qquad s\in[0,1]. \]

模型学习：

\[ \mathcal L_{\mathrm{FM}} =\mathbb E_{(c,A),s,\epsilon} \left[\|v_\theta(x_s,s,c)-(A-\epsilon)\|_2^2\right]. \]

每个训练样本给出一对端点和一条路径上的监督速度。模型只看到当前点与条件，需要把大量样本的信息汇总成可用的速度场；它并没有在推理时提前知道目标动作。Flow Matching 也可以采用其他概率路径，线性插值只是常用示例。Flow Matching 原论文

推理时求解：

\[ \frac{dx_s}{ds}=v_\theta(x_s,s,c),\qquad x_0\sim\mathcal N(0,I). \]

这里的速度是动作张量沿生成过程的变化率，通常不是机器人关节速度。生成时钟 \(s\) 也不是机器人实际执行的秒数。动作生成完成后，控制器才根据动作定义执行输出。

8. Normalizing Flow：可逆变换与显式密度

“Flow”并不唯一指 Flow Matching。Glow 属于由可逆变换组成的 Normalizing Flow（NF，归一化流），典型训练目标是负对数似然。Flow Matching 则学习连续生成过程的速度场。二者都有把简单分布变成复杂分布的思想，但其网络约束与训练目标不同。

设 \(x\in\mathbb R^d\) 是连续样本，例如展平后的动作块或一组抓姿参数；\(c\) 是观测条件；\(f_\phi\) 是对 \(x\) 可逆、参数为 \(\phi\) 的变换。约定从数据到简单 latent 的方向为：

\[ z=f_\phi(x;c),\qquad \log p_\phi(x\mid c) =\log p_Z(z) +\log\left|\det\frac{\partial f_\phi(x;c)}{\partial x}\right|. \]

\(p_Z\) 是容易采样和计算密度的基础分布，如标准高斯；\(\partial f_\phi/\partial x\) 是 Jacobian 矩阵；其行列式的绝对值校正变换造成的体积变化。训练最大化数据的 log-likelihood，等价于最小化：

\[ \mathcal L_{\mathrm{NLL}} =-\mathbb E_{(x,c)\sim\mathcal D}\log p_\phi(x\mid c). \]

生成时反过来，先采样 \(z\sim p_Z\)，再计算 \(x=f_\phi^{-1}(z;c)\)。可逆结构让模型同时支持计算密度与生成样本；它不是把当前样本与另一条随机生成样本直接做 MSE。

8.1 概率密度不等于一个精确样本的概率

连续分布通过对区域积分得到概率：

\[ \Pr(x\in B\mid c)=\int_B p_\phi(x\mid c)\,dx. \]

\(B\) 是样本空间中的一个区域。密度可以大于 1，例如在长度为 0.1 的区间上均匀分布，其区间内密度为 10，而积分后的总概率仍是 1。因此，正的 log-likelihood 并不违反概率规则。

密度数值还依赖单位、参数化与参考测度；位置从米改成厘米，密度数值会随坐标尺度变化。比较 log-likelihood 时必须保持数据表示与归一化协议一致，不能把不同实现下的绝对数值直接当作通用模型排名。较高似然说明数据分布拟合的一面，不直接保证物理可行或闭环成功。

8.2 条件分解保留变量之间的关系

将生成对象从动作块换成静态抓姿，记为 \(g=(R,\mathbf t,\mathbf q)\)：\(R\) 是手根旋转，\(\mathbf t\) 是位置，\(\mathbf q\) 是关节角，\(X\) 是物体或场景点云。按概率链式法则：

\[ p(g\mid X)=p(R\mid X)\,p(\mathbf t,\mathbf q\mid X,R). \]

这个分解允许先选朝向，再在该朝向下联合决定位置与手型。它没有假设位置与关节互相独立；进一步写成

\[ p(\mathbf t,\mathbf q\mid X,R) =p(\mathbf t\mid X,R)\,p(\mathbf q\mid X,R,\mathbf t) \]

同样是合法的条件分解。若把后项中的 \(\mathbf t\) 删除，才额外引入条件独立假设。论文写“拆分建模”时，需要查清其实际条件依赖，不能自动补成独立分布相乘。

旋转所在的 \(\mathrm{SO}(3)\) 是三维旋转群，不是没有约束的普通三维向量空间。Implicit-PDF 用网络评价候选旋转的密度，为旋转分布提供一种建模方式。它与位置／关节模型可以组合；如何组合及其效果需要实验检验，不能由分解公式本身保证。

9. 生成一致性与采样蒸馏

扩散和 Flow Matching 常用多次网络前向得到动作。生成一致性与采样蒸馏关注另一条轴：在保留生成质量的同时，减少需要的前向次数。

一致性模型希望同一生成轨迹上不同噪声级的点映射到相同端点。一个示意目标是：

\[ \mathcal L_{\mathrm{cons}} =\mathbb E\left[ w(s,s')\,\ell\left( f_\theta(x_s,s,c), \operatorname{sg}[f_{\bar\theta}(\tilde x_{s'},s',c)] \right)\right]. \]

其中 \(\operatorname{sg}\) 表示停止梯度，两个输入必须按相应算法构造，端点还需满足边界条件。这不是把两个独立带噪样本随意拉近；仅让两边输出相同也不足以排除无意义的常量解。不同算法对配对、目标网络和加权有不同规定。

一般采样蒸馏还可以让学生直接模仿教师多步采样的结果：

\[ \mathcal L_{\mathrm{distill}} =\mathbb E_{z,c} \|G_\theta(z,c)-\operatorname{sg}[S_{\mathrm{teacher}}(z,c)]\|_2^2. \]

这里假设教师采样是确定性的，或已固定教师中途的随机性，使同一份噪声与条件对应确定目标。这只是最直观的端点蒸馏示例，不代表所有蒸馏方法。教师的生成偏差也可能被学生继承。具体训练方式及其与表征一致性的区别，见 生成一致性与采样蒸馏。

Diffusion 噪声、干净样本或其他目标 采样器多步恢复动作 采样步数、参数化与噪声调度
Flow Matching 生成路径上的速度 数值积分得到动作 路径、积分器与步数
Glow 一类 Normalizing Flow 数据负对数似然 基础随机变量经过可逆变换 可逆结构、密度计算与表示空间
Consistency / 蒸馏 轨迹端点一致性或教师目标 一步或少步生成 配对与边界条件、教师误差、质量权衡

“Transformer”描述计算结构，“CVAE / diffusion / flow”描述学习与生成方式，“action chunk”描述输出覆盖的时间范围。三者可以组合，所以不能仅凭用了 Transformer 或输出多步动作，就判断它的 loss。

同一个 VLA 也可以同时接受两种动作监督：把专家动作编码为 FAST tokens，用 next-token 交叉熵训练 VLM 的动作表示；同时构造带噪动作，用 flow loss 训练连续 Action Expert。训练时保留离散分支，推理时仍可只由 expert 生成底层动作。KI 就采用这种联合训练，并限制 flow 梯度回到主干的路径。KI 原论文

这里不能得出“交叉熵天然优于 MSE”。两者比较的是 token 类别与连续速度等不同目标；第 2 节确定性动作回归的均值问题，也不能直接套在以噪声和生成时间为输入的 flow 模型上。判断收益要结合表示、条件输入、梯度路径与推理方式。π₀.₅ 原论文、官方 checkpoint 和公开微调代码之间的区别，见 FAST 与 KI：动作监督、梯度与微调。

具体例子可以连接到 ACT / DP、PI0.5、GR00T 与 FuSe。这些例子说明可用组合，不构成对整个领域使用比例的统计。

11. 训练计算、采样计算与控制反馈

Diffusion 和 Flow Matching 的常见训练方式是随机采一个噪声级或生成时刻，只做一次带噪前向；推理才进行多步采样。某些蒸馏方法需要额外教师计算，不能用这个简化描述覆盖所有训练算法。

生成一个动作块后，还要选择执行多少步再接收新观测：

训练：一段示范 → 构造目标 → 前向 → loss → 更新参数
采样：当前条件 + 随机变量 → 一次或多次前向 → 动作块
执行：动作块的短前缀 → 新传感器观测 → 再次生成

减少生成步数可能降低推理耗时，但闭环反馈还受相机、触觉、通信和控制器影响。网络输出也要经过反归一化、坐标和单位转换；学习到合理动作分布并不自动保证控制接口正确。

本文的知识链可以概括为：数据定义需要学什么，生成目标定义怎样学，网络提供计算能力，采样器产生候选动作，执行系统决定动作何时真正影响机器人。 对应的部署时间轴见 在线执行与 Action Chunk 调度。

12. 候选生成与样本级优化

生成器可以先提出候选抓姿，再用接触、碰撞或任务约束修正这个样本。设 \(\xi\) 是待优化的抓姿参数，\(g(\xi)\) 将参数转换成有效的旋转、位置与关节配置；\(E(g(\xi);X)\) 是结合当前场景 \(X\) 的优化代价。一个示意更新是：

\[ \xi^{(k+1)}=\xi^{(k)}-\eta\nabla_\xi E(g(\xi^{(k)});X). \]

\(k\) 是优化迭代编号，\(\eta\) 是步长。这次被更新的是当前候选的 \(\xi\)，不是生成器的权重；旋转参数还需采用适当参数化或约束，不能直接把旋转矩阵当任意向量修改。

训练网络：训练数据 → loss → 更新网络参数 φ
生成候选：当前条件 + 随机变量 → 固定网络 → 初始样本 ξ⁽⁰⁾
修正样本：当前场景 + 几何代价 → 优化 ξ → 修正后的抓姿
闭环执行：当前观测 + 目标抓姿 → 控制策略 → 动作

术语 Test-Time Adaptation（TTA）在不同领域可能指更新权重，也可能指优化输入或输出变量，必须检查优化器管理的对象。在 UniDexGrasp 的 TTA 实现 中，优化器管理当前 hand_pose；它不等于继续训练 PPO，也不等于运行历史适应 Encoder。

若删除测试时修正，生成网络仍可能在训练期受过接触或碰撞损失监督。训练阶段的辅助 loss 与推理阶段的样本优化，需要分别画在各自计算图上。
