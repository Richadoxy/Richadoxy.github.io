## 1. 主线与三项拟定贡献

典型场景是一只手先拿起 A，把 A 移到掌部可承托的位置，空出部分手指继续抓 B。物体进入手内后，外部相机难以看到接触细节；此时调整或释放 B，可能同时撤掉 A 的支撑。

全掌触觉观察掌心和指节上的接触变化，灵巧手主动重分配这些接触。要研究的中间状态是：**每个已知物体由哪些区域支撑，这些归属如何随动作迁移，以及哪些归属暂时无法确定。** 压力传感器不直接测量物体身份，需要视觉初始化、交互历史和动作信息共同推断。

核心假设：遮挡与后续扰动下，对象级接触记忆比同样拥有完整触觉和历史的全局表示，更有利于选择性控制。若 global temporal baseline 同样有效，就应收缩表示贡献；只有归属预测提升、没有控制收益，也不足以支持完整主张。

| 拟定贡献 | 具体内容 | 必须提供的证据 |
| --- | --- | --- |
| 遮挡下多物体选择性操作协议 | 获取、掌内迁移、选择性释放，同时评价目标完成与保护对象保持 | 遮挡后扰动、角色交换、独立成功判定、跨物体组合测试 |
| Object-centric tactile memory | 视觉身份 anchor + 全掌区域触觉 + 因果历史，维持对象接触归属及不确定性 | 与同传感器、同历史的全局记忆比较；归属监督和记忆消融 |
| Target/protected 条件控制 | 动作同时考虑要操作的对象与必须保留的对象，持续读取新触觉 | 更少保护物体掉落/误释放，同时完成目标迁移或释放 |

贡献重心是对象状态接口及其控制收益。atlas、ViT、GRU、Diffusion Policy 和 RL teacher 分别承担编码、记忆、动作生成与数据生成的实现角色，使用这些组件本身不构成新颖性。

语言可表达目标，但第一版用结构化条件即可：`target_object`、`protected_objects`、`destination_region`、`operation`。RDP 保留为反应式 baseline 或后续动作头；T-Rex、π0、三物体、双手协作和自由语言生成暂不进入必需范围。

## 2. 三类任务与遮挡协议

| 任务 | 操作要求 | 需要解决的问题 |
| --- | --- | --- |
| Acquire-and-store | 抓 A，转移到可承托的储存区，再抓 B，最终稳定持有两者 | A 是否真正被存放，哪些手指可用于 B，原有支撑是否被破坏 |
| Retain-and-relocate | 保持 A，把 B 移到另一可达掌区并稳定 | 接触迁移属于谁，移动 B 是否带动或挤掉 A |
| Selective release | 将指定物体送入接收区，继续持有另一物体 | 哪些接触应解除、哪些必须保留，避免放错或同时掉落 |

先限定两个物体，平衡 A/B 的物理身份、获取顺序和任务角色，不能把 slot 0 永久等同于保护对象。掌区使用经实物核对的手部坐标系；压力峰值移动不等于物体真的移动到目标区域。

固定腕部、预放置物体可以验证存放/调整原语，但不等于完成从桌面获取两个物体。臂/腕用于接近、获取和释放，掌部提供支撑，不假设掌心有额外驱动。夹具可帮助初始化，自主保持与成功计分阶段不能依赖外部承重。

**主遮挡协议：**遮住手内及已持有物体，桌上的下一目标可在接触前继续被看到；B 进入手内后不能从外部图像刷新其隐藏状态。另设共同初始观察后关闭全部外部相机的条件，只测试已初始化对象，不要求定位从未看过的目标。

所有方法获得相同的初始视觉、允许后续图像、目标和机器人状态。遮挡使用物理挡板或由机器人运动学确定的保守手部包络，不能用隐藏物体真值生成随物体移动的 mask 边缘。独立评测相机、跟踪器及仿真真值只用于标注/评价。

遮挡以后再随机施加位移、轻推或接触扰动，并变化目标掌区和保护角色，检验新触觉是否改变纠正动作，避免固定动作序列也能解决任务。

## 3. O-TAC 网络与已实现边界

当前 PyTorch 原型在 `/home/xyd/otac`，数据流已实现：

```text
压力 + validity → 三通道数值 atlas → 小型 ViT / 区域池化 ─┐
区域压力 / 接触比例 / 压力变化 / 有效覆盖率 ─────────────┤
五指 depth 可视化 → 共享 CNN + 手指身份 / validity ─────┘
                                    ↓ 区域触觉 tokens
允许的物体 crop + 图像 box → 初始身份 anchor ──────────┐
q / 上一次实际发出命令 / observation age ──────────────┤
                         物体 cross-attention + GRU memory
                                    ├→ ownership / known-owner 辅助头
                                    ↓
target / protected / other 角色 + 目标掌区 + 操作 + context
                                    ↓
               条件 Diffusion Policy → H 步动作 → 执行短前缀
                                    ↑ 每个新观测持续更新记忆
```

### 3.1 表示、记忆与控制

- atlas 通道是数值压力、当前测量有效性、静态几何占位，不是 RGB 热力图。无可靠二维映射的通道仍可进入区域统计，不能当作零接触。
- 五指用共享 CNN，保留手指身份。旧 depth 只当灰度外观；物体视觉编码器也是小型 CNN，没有自动检测器或预训练视觉基础模型。
- 首次允许视觉观测建立固定 `anchor` 与动态 `slot`，遮挡期间仅用允许信息更新 slot。crop 外还需 box，外观本身不提供接近位置。
- `object_active` 表示本 episode 已知存在的身份，不能根据隐藏掉落真值关闭它；同形物体发生不可观测交换时，不能保证恢复身份。
- ownership 是独立的物体×区域 logits，同一区域可涉及多个物体；传感器无效、没有接触、归属未知分别处理。
- known-owner 头需要独立标签和有效性掩码；未经监督和校准的 sigmoid 值不是可信概率或保持保证。
- 当前动作 context 读取 slots/anchors、角色、触觉和本体信息；ownership/known-owner 是辅助头，**没有把预测接触图单独接成动作筛选器**。
- 动作头用 Transformer 去噪器，训练 DDPM 噪声预测、推理 DDIM。默认预测16步、执行前缀1步，这是配置，不代表已测得某个真机反馈频率。

默认7个区域、2个对象槽位。两个掌区按二维 mapping 的 `u` 轴划分，未经实物核对不能直接命名为拇指侧/小指侧。21维手动作与28维臂手示例已通过软件流程检查，但独立控制自由度、耦合、单位和限位仍以真实控制器为准。

### 3.2 损失、训练与推理

| 代码阶段 | 已实现损失 | 数据前提 |
| --- | --- | --- |
| `stage=pretrain` | 有效压力遮挡重建 + 区域接触 BCE | 可无动作；无效通道/未知负例不能充当监督 |
| `stage=policy` | 动作扩散损失 + 可选 ownership BCE + 可选 known-owner BCE | 有效执行命令、明确目标和允许的视觉身份；辅助头另需部分标注 |

策略训练保留从 episode 初始化到决策时刻的完整前缀；当前实现对其反传，长序列增加显存开销。推理记忆由调用者持有，每个新观测只更新一次；消费动作片段期间也更新，不能重复编码重叠历史。

当前 `--pretrained` **只迁移 `tactile.*`**，其余视觉、物体记忆和动作头重新初始化。sim 策略到 real 的全模型适配流程仍需实现和验证；`--resume` 用于同一训练任务恢复，不能当作跨数据域微调接口。

尚未实现真实机器人适配器、全6D物体重建、标定 taxel 动力学、独立保留风险预测/动作重排和慢快残差控制。软件测试通过不等于机器人学会操作，详细实现以 `/home/xyd/otac/docs/architecture.md` 和源码为准。

## 5. RL teacher → 专家数据 → O-TAC

### 5.1 职责与课程顺序

RL 承担专家动作生成和机械可行性探索。沿用 RevoLab / Isaac Lab / 自定义 RSL-RL，以 PPO teacher 为起点。论文主线仍围绕对象级触觉记忆及真实选择性控制，奖励工程暂不单列为新贡献。

建议逐级推进，每一级先看物理行为和视频，再看 reward 曲线：

1. **单物体存放 A**：A 预放置在可接触位置，通过手指动作转移至可承托目标区，连续稳定保持。
2. **保持 A，再抓 B**：A 起始已存放，B 位于工作指可达支撑面；B 离开支撑后仍稳定持有，同时 A 不掉落。
3. **保持 A，迁移 B**：在至少两个验证可达的区域间移动 B，同时保持 A；加入角色交换与扰动恢复。
4. **选择性释放**：目标进入接收区域，保护对象仍在手内。
5. **组合与臂手扩展**：加入接近、桌面获取、腕部动作，连接完整任务。

`/home/xyd/otac/rl_extension/otac_rl/` 有前两级原型草稿（`OTAC-Revo3-StoreA-v0`、`OTAC-Revo3-KeepA-GraspB-v0`），尚未环境验收或训练。文件存在不表示任务跑通；预置 A、近指支撑台上的 B 属于原语课程，不等于完整桌面多物体抓取。

### 5.2 Reward 与独立成功判定

奖励围绕物体在手坐标中的进展、连续稳定保持、保护物体不丢失、正确释放，并惩罚过大动作变化、过压/穿透和超时。距离 shaping 可用有界势函数增量，注意真实终止与 time-limit truncation 的区别。

不能只奖励接触多、压力大或目标靠近，否则可能夹死、依赖桌面承重、穿透、甩出，或只完成 B 而丢掉 A。成功独立检查目标位置/接收容器、保护对象保持、速度与连续稳定时长、解除外部支撑；阈值在机械 pilot 后固定。仿真可用接触对和几何真值评价，真实实验需独立测量。

### 5.3 特权 teacher 与可部署 student

初期 teacher 可读取仿真物体位姿、速度与接触归属，降低探索难度。它是**特权数据生成器**，不是可直接部署的 O-TAC。执行需要真机不可得的隐藏状态时，必须先蒸馏为只依赖可用触觉/状态/允许视觉历史的闭环策略，或实现并验证状态估计，不能在真机接口填仿真真值。

另可采用 actor 只读可部署观测、critic 读特权信息的非对称训练；这仍需验证可观测性和探索难度，不当作已实现方案。

刚体接触力或 link×object 接触矩阵可监督粗区域归属，但**不是301路真实 taxel，也不是 ViTai depth 图像**。没有可信传感器模型时，可先学习动作/对象状态部分，再用真实触觉训练 encoder；不能复制 link force、伪造 depth 后声称生成了逼真全掌数据。未建模的模态应明确 invalid。

### 5.4 真机 replay 与 sim2real

- **轨迹 replay**：先当候选参考动作，在匹配初始条件下有限执行并记录真实反馈。相同关节轨迹不保证相同接触；失败 replay 不是合格专家动作或成功示范。
- **闭环 sim2real**：策略持续读取真实触觉/状态。质量、摩擦、驱动、延迟、噪声和标定偏差可做随机化，但不能替代真机验证和适配。
- **质量筛选**：合格成功与恢复动作进入模仿监督；失败保留原因和用途，不全部作为普通 BC 标签。只保留平稳成功段也会遗漏恢复能力。
- **左右手统一**：真实旧数据是左手，已验收 USD 是右手。先选定平台或建立验证过的左右映射，不能只镜像图像/重命名关节就迁移动作、掌区和触觉。

## 6. 实验与 baseline

| 比较组 | 方法 | 要回答的问题 |
| --- | --- | --- |
| 传感器 | DP：视觉+本体；再加五指视触觉；再加全手压力 | 触觉是否改善同一任务 |
| 掌部覆盖 | 全输入模型与移除36路掌压的独立训练模型 | 掌压是否提供指尖和指节压力之外的信息 |
| 时间与对象表示 | 全输入 Global Temporal DP，获得相同历史、身份初始化、目标与反馈 | 对象级记忆是否优于一般时序融合 |
| 反应式反馈 | 适配到相同输入/任务的 RDP | 收益是否仅来自执行期间触觉刷新 |
| 本方法 | O-TAC | 对象记忆与目标/保护条件是否改善选择性操作 |

优先保证 global temporal 和 no-palm 对照，不能只打败无触觉模型就证明物体记忆有效。RDP 灵巧手适配尚未实现；ACT 可作补充。特权状态 oracle 单列，不能混入可部署方法的公平主比较。

所有方法独立训练，尽量匹配示范量、预训练数据、目标与身份信息、动作定义、历史长度、规划/执行长度、反馈频率、容量和计算预算，报告无法匹配的差异。full tactile 对比 fingertip 同时改变覆盖范围与传感器类型，需要 no-palm 和可选 pressure-only 对照帮助归因。

关键消融：slots 改为 global memory；去掉 ownership 监督但保留 slots；保留初始身份而重置动态记忆；去掉掌压；无感知预训练。验证“保留”机制时，各方法都应知道哪个对象要被保护。

**主指标是联合成功：目标完成且保护对象仍被保持且最终状态稳定。** 辅以目标达区/入容器、各物体掉落率、错误释放率、保护对象非预期位移、完成/恢复时间、压力饱和和传感器到命令的延迟。

ownership 仅在独立确认的部分标签上评价，不能用模型自己的接触图评分。未标定压力不报告为牛顿，离线命令误差不报告为闭环成功率，掌内迁移要通过物体几何位置核对。

泛化分别测试新初态、已知物体的新配对、未见物体和新 session。主结果使用多个 seed 与独立 episode，按场景配对并随机执行顺序；试验次数与置信区间由真实记录产生。论文 PH 表格不设为目标成绩或当前性能。
