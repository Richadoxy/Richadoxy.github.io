# RL 实验阅读：从指标、分布到消融证据

> 阅读位置：[RL 研究地图](43_dexterous_rl_overview.md) → [Actor–Critic 与 PPO](44_rl_basics_and_training_loop.md) → [Teacher–Student](45_teacher_student_and_sim_to_real.md) → 本文。随后可对照 [HORA 精讲](46_hora_paper_walkthrough.md) 和 [UniDexGrasp 精读](47_unidexgrasp_paper_walkthrough.md)。本文整理通用的读表与实验设计方法，数值例子均为教学示例，不是论文结果。

## 1. 先确定实验到底在评价哪一个对象

同一篇机器人论文可能依次训练生成器、特权策略和感知策略，再组合成完整系统。它们的指标属于不同层级，不能直接互相替代。

~~~text
观测 → 生成器 → 候选目标 → 选择或优化 → 控制策略 → 环境结果
       │          │                      │           │
       密度拟合   几何质量、多样性          控制行为     任务成功、目标误差

控制策略训练：特权 Teacher → 模仿／蒸馏 → 可部署 Student
                        各阶段分别评价，再检查完整流程
~~~

| 评估对象 | 可以回答的问题 | 不能直接推出的结论 |
| --- | --- | --- |
| 静态抓姿生成器 | 生成的手型是否合理、多样、少穿透 | 机器人一定能运动过去并抓起来 |
| 特权状态 Teacher | 在输入充分时能否学会控制 | 只靠相机或触觉也能达到相同表现 |
| 感知 Student | 受限输入下能否闭环执行 | 真机传感器和动力学误差已经解决 |
| 完整仿真流程 | 上游误差进入控制后是否还能成功 | 已完成真实部署验证 |
| 真机流程 | 在实际机器人与测试条件下是否有效 | 对任意物体、任务与场景都能泛化 |

记录一张表时，先写出它的“评估合同”：**哪一个模型、什么输入、哪一批任务、在哪里运行、成功条件是什么**。这比先找加粗数字更能防止误读。

## 2. 泛化分布与运行环境是两条独立坐标

### 2.1 训练物体、新实例与新类别

物体抓取论文常将评估分成三个范围：训练过的物体、已见类别中的新物体、未见类别的物体。例如训练使用若干杯子，换一个新杯子测试实例泛化；若训练完全没有锤子，再测试锤子则涉及类别泛化。这个例子只说明划分语义，不代表两类物体必然具有固定的难度顺序。

表头的 `Train` 通常表示在训练物体集合上评估完成后的模型，并非训练损失或训练回报。还要检查物体身份以外的随机因素：初始朝向、目标抓姿、物理参数和相机条件是否重新采样。

`Within training distribution` 描述测试条件是否来自训练分布；`out of distribution` 描述分布发生了变化。变化可能来自物体身份、几何、质量、摩擦、目标或传感器，不必同时改变所有因素。

### 2.2 仿真与真机描述执行地点

| | 分布内测试 | 分布外测试 |
| --- | --- | --- |
| 仿真 | 按训练时的任务与参数采样分布重新采样 | 改变仿真物体、参数范围、采样权重或任务条件 |
| 真机 | 尽量匹配已知任务与物体条件，但仍有物理域差异 | 真机上进一步换物体、任务或扰动条件 |

参数范围相同也不保证分布相同：在同一区间内改变采样权重，就可能改变分布。真实系统不能仅凭“物体与训练相同”就被认定为完全处于训练分布内。需要明确作者所说的“分布内”具体指哪个变量。类似地，仿真中的分布外表现也不能替代 sim-to-real 实验。

## 3. 对照实验不一定是在删除网络

| 实验类型 | 实际操作 | 典型证据 |
| --- | --- | --- |
| 方法 baseline | 换一种完整解决方案，如规划、RL 或示范辅助学习 | 新方案相对替代路线的表现 |
| 网络模块消融 | 删除或替换编码器、记忆模块、动作头 | 该结构是否有助于学习或执行 |
| 监督消融 | 保留主干，删除辅助 loss 或标签 | 某种监督是否改善表示或控制 |
| 训练流程消融 | 改课程、reset 分布、数据混合或预训练 | 数据与探索顺序是否影响可学性 |
| 推理机制消融 | 冻结 latent、关闭反馈、跳过样本优化 | 已训练系统是否利用该机制 |
| 输入鲁棒性测试 | 固定模型，改变噪声、遮挡或目标误差 | 对指定扰动的容忍范围 |
| 任务定义对照 | 改目标输入、奖励或成功标准 | 能力要求变化后的结果 |
| 特权参考 | 给模型更多隐藏信息 | 信息充分时的参考表现，不保证数学上的性能上界 |

DR、SysID、DAgger、PPO 和 Teacher–Student 也处于不同层级。DR 改变训练环境分布，SysID 估计系统属性，DAgger 组织交互式模仿数据，PPO 更新策略，Teacher–Student 组织模型间的学习关系。它们不是一组固定的消融名称。

### 3.1 重新训练与测试时关闭模块是不同问题

~~~text
训练消融：修改结构／监督／课程 → 重新训练 → 统一评估
机制诊断：同一个已训练模型 → 测试时关闭机制 → 评估退化
鲁棒性：  同一个已训练模型 → 扰动输入或环境 → 评估退化
~~~

如果删掉目标输入后重新训练，得到的是适应新任务的策略；如果测试时突然把目标置零，可能只是制造了一种模型没见过的输入。两者不能混用同一个结论。消融图应该标明“重新训练”或“权重固定”，并标出改动发生在网络、loss、数据还是推理流程。

### 3.2 控制变量与贡献边界

当两个方法同时改变观测、奖励、交互预算和网络，结果可以比较整套方案，却不能将差距全部归因于某个模块。更清楚的报告方式是：先比较完整系统，再对关键设计做控制变量实验。

删除一个设计导致性能下降，说明它在当前组合和协议中有帮助；并不证明所有任务都需要它，也不证明另一种实现无法替代它。若去掉课程后训练集表现也很差，瓶颈可能首先是优化与探索，而不是测试泛化。

## 4. Reward、成功率和误差衡量不同的事情

Reward 是训练信号，通常组合任务进展与正则项。改变 reward 权重会改变数值尺度，所以不同奖励函数下的累计回报不能直接比较。独立的成功标准可以帮助判断策略是否真正完成任务。

设有 \(N\) 次评估，第 \(i\) 次的成功标记为 \(S_i\in\{0,1\}\)，经验成功率为：

\[
\widehat p_{\mathrm{success}}=\frac{1}{N}\sum_{i=1}^{N}S_i.
\]

这里的“一次”必须由实验协议定义：是一次从重置开始的 episode，还是允许多次重试后的整项任务。终止条件、时间限制、掉落处理与成功后的保持时间都可能改变成功率。

### 4.1 完成任务与遵循目标应分别测量

若目标指定手型或轨迹，抓起物体并不足以证明遵循了目标。可以同时报告任务成功与目标误差。一个三维关节位置误差示例是：

\[
e_i=\frac{1}{J}\sum_{j=1}^{J}
\left\|\mathbf p_{i,j}^{\mathrm{actual}}-\mathbf p_{i,j}^{\mathrm{goal}}\right\|_2.
\]

\(J\) 是关节数量，\(\mathbf p_{i,j}\) 是第 \(i\) 次执行中第 \(j\) 个关节的三维位置，\(\|\cdot\|_2\) 是欧氏距离。若位置以厘米表示，误差单位也是厘米。关节位置可以由关节角经过正向运动学得到，所以这个量既不是关节角误差，也不是动作预测 MSE。

最终一帧的误差、整段轨迹的平均误差与最大误差同样不同。论文写 `pose error` 时，应继续查它比较的是哪些位置、朝向或角度，以及在哪些时刻计算。

### 4.2 只在成功样本上统计误差，会改变比较的样本集合

若只在成功执行上统计误差，实际报告的是：

\[
\widehat e_{\mathrm{success}}
=\frac{\sum_{i=1}^{N}S_i e_i}{\sum_{i=1}^{N}S_i},
\qquad \sum_i S_i>0.
\]

分母是成功次数，不是全部评估次数；没有成功样本时，该指标未定义，不能记为零。两个方法成功的物体可能不同，因此即使都叫“平均误差”，也未必在同一批样本上平均。

例如方法 A 在 100 次中成功 5 次，成功样本平均误差为 1 cm；方法 B 成功 80 次，误差为 2 cm。不能只据此断言 A 的整体控制更好。它可能仅在少量简单情况成功。

若任务同时要求成功和目标精度，可以另报告联合通过率：

\[
\widehat p_{\mathrm{joint}}
=\frac{1}{N}\sum_{i=1}^{N} S_i\,\mathbb{1}[e_i\leq\varepsilon],
\]

其中 \(\mathbb{1}[\cdot]\) 表示条件满足时为 1，\(\varepsilon\) 是事先确定的允许误差。这是可采用的补充评估方法，不表示已有论文都报告了这个指标。

## 5. 生成质量、多样性、似然与执行性能

抓姿生成位于控制之前，通常同时有几个目标：符合参考数据、覆盖多种可行解、避免几何穿透，并且可被控制器执行。它们之间没有自动等价关系。

| 指标类别 | 实际测量 | 阅读边界 |
| --- | --- | --- |
| 分析式抓取质量 | 给定接触几何下抵抗扰动的能力 | 依赖接触和摩擦假设，不等于动态执行成功率 |
| 穿透／接触 | 手物或手桌的几何关系 | 明确测目标抓姿还是执行过程，明确符号和阈值 |
| 样本多样性 | 多次生成结果的分散程度 | 无效样本也可能很分散，须结合质量 |
| 数据 log-likelihood | 模型给参考样本的对数密度 | 依赖变量尺度与密度定义，不是成功概率 |
| 下游执行成功率 | 控制器能否执行生成目标 | 同时受生成器、目标选择和控制器影响 |

抓取质量指标中的 \(Q_1\) 与 RL 的 \(Q^\pi(s,a)\) 只是符号相似。后者是某策略下的期望折扣回报；前者来自抓取力学评估。符号必须放回原文定义。

### 5.1 条件多样性：固定一部分后，还剩多少变化

若抓姿包含旋转 \(R\)、位置 \(\mathbf t\) 与关节配置 \(\mathbf q\)，整体样本变化很大，可能只因为旋转变了。固定同一个 \(R\)，再检查 \(\mathbf t\) 和 \(\mathbf q\) 的变化，可以更直接检查模型是否覆盖不同抓取位置和手型。

“给定 \(R\)”是一种条件控制，不意味着位置和关节彼此独立。条件联合分布 \(p(\mathbf t,\mathbf q\mid X,R)\) 仍可保留它们之间的关联。概率分解、连续密度与 Normalizing Flow 的基础见 [动作生成方法](25_action_generation_families.md)。

### 5.2 几何判无效与动态失败不是同一件事

若指标规定超过穿透阈值就将质量记零，零分包含了评测规则的影响，不能擅自改写成“机器人执行成功率为零”。同样，一个经过优化的高质量静态抓姿，也没有保证从给定初始状态到该抓姿的路径可行。

## 6. 多阶段系统如何定位误差来源

假设完整流程为“生成目标 → Student 执行”，可以固定 Student，分别输入参考目标、预测目标与不同程度的扰动目标。它们依次检查目标来源变化、小误差容忍度与失败边界。

~~~text
参考目标 ────────────────┐
生成目标 ────────────────┤
生成目标 + 指定扰动 ──────┴→ 同一个固定控制器 → 独立任务指标
~~~

小扰动下性能保持较好，只支持对这一种、这一范围的扰动具有一定鲁棒性。大扰动后失效有助于识别系统边界，也不应被平均数掩盖。

Teacher 与 Student 的差距也需要在匹配目标来源、物体、reset、控制频率和成功标准后比较。若 Teacher 使用生成目标，Student 使用参考目标，直接相减就混入了目标质量差异；若表格来自不同实验批次，也不应擅自拼成一个严格配对的蒸馏消融。

输入可部署性还要沿计算依赖追查：一个名为 `goal_delta` 的量，可能需要当前物体真值位姿才能构造。“输入列表没有 object pose”不自动等于没有读取特权信息。该问题属于数据来源审计，和网络是否有 Encoder 是两个维度，见 [Teacher–Student](45_teacher_student_and_sim_to_real.md)。

## 7. 随机种子、曲线阴影与预算

一次训练会受到初始化、动作采样和环境随机性的影响。训练随机种子与评估 episode 的随机种子也不是同一层重复：在一个模型上测试很多次，可以提高该模型的成功率估计精度，却不能替代训练多个独立模型。

读 `均值 ± 数字` 或曲线阴影时，需查看它究竟表示标准差、标准误还是置信区间。标准差描述样本分散程度，标准误与均值估计的不确定性有关，置信区间还依赖构造方法。图中没有说明时，应保留未知，不能自行命名。

对简单独立同分布样本，样本均值 \(\bar x\) 的标准误常估为 \(s/\sqrt n\)：\(s\) 是样本标准差，\(n\) 是独立样本数。但机器人评估可能在物体、episode、训练种子之间存在分组依赖，不能把同一条轨迹中的每个时间步都当成一个独立样本扩大 \(n\)。

曲线横轴同样决定结论：环境交互步数衡量样本预算，训练迭代数依赖每轮采样量，墙钟时间还受硬件和并行度影响。课程或示范预训练的成本需要纳入所声称的效率指标。更早达到阈值与最终成功率更高，是两个不同的实验主张。

多任务评估还要说明按 episode、物体还是类别加权。大量简单物体可能主导整体均值。关于 RL 中少量训练运行的不确定性和聚合指标，可继续阅读 [Agarwal 等的评估研究](https://papers.nips.cc/paper/2021/hash/f514cec81cb148559cf475e7426eed5e-Abstract.html)；关于复现与随机性，参见 [Henderson 等](https://ojs.aaai.org/index.php/AAAI/article/view/11694)。

## 8. 将实验变成可复查的知识记录

每项核心设计可以记录为一行，而不是只摘录最佳数字：

| 项目 | 应记录的内容 |
| --- | --- |
| 主张 | 希望改善探索、表示、泛化、执行精度还是部署 |
| 改动位置 | 输入、网络、loss、数据、课程、推理或任务定义 |
| 训练处理 | 重新训练、继续训练、仅测试时切换；哪些参数固定 |
| 控制变量 | 观测、目标、奖励、预算、物体、初始化、执行接口 |
| 指标 | 公式、单位、阈值、统计时刻、失败是否计入 |
| 不确定性 | 训练种子、评估次数、聚合方式、误差条含义 |
| 支持的结论 | 当前设置下哪个设计有效，仍缺少哪些层级的证据 |

在 [HORA](46_hora_paper_walkthrough.md) 中可用它区分 DR、SysID、停止更新 latent 和特权参考；在 [UniDexGrasp](47_unidexgrasp_paper_walkthrough.md) 中可用它区分生成模型替换、辅助分类、物体课程、TTA 和目标扰动。遇到新论文时，沿着“主张 → 操作 → 指标 → 证据边界”记录，就能把不同名字的实验放到相同的比较坐标上。
