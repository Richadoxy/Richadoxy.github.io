# 触觉输入表示：从传感器读数到策略条件

> 本文整理触觉模仿学习中的输入设计：先辨认传感器测到了什么，再保留空间、时间与有效性，最后把它变成策略可读取的条件。重点是小型视觉—触觉策略，具体维度均为可替换的设计示例。
>
> 后续阅读：[策略记忆与对象级触觉状态](40_policy_memory_and_object_centric_tactile_state.md)、[触觉记忆的实验设计](41_tactile_memory_experiment_design.md)。论文实例可参考 [RDP](35_rdp_paper_reading_notes.md)、[T-Rex](34_trex_paper_reading_notes.md) 与 [Tactile-VLA](30_tactile_vla_physical_knowledge_paper_reading_notes.md)。

## 0. 输入设计与可学习的信息

假设掌面左右两侧都可能接触物体。若把整张压力图只压成“总读数 100”，左侧接触与右侧接触就可能变成相同输入。之后即使换更大的网络，也无法从这个数还原被提前丢掉的位置。

另一种情况是逐帧把压力除以本帧最大值。轻触和重压只要形状相似，就可能得到几乎一样的归一化图。模型仍能看见接触轮廓，却不容易判断这次到底压得多重。

因此，触觉输入首先是一个信息保留问题：

```text
真实接触
   ↓ 传感器响应与标定
数值、图像、有效性、时间戳
   ↓ 保留位置与物理含义
局部特征 / 区域 tokens
   ↓ 与视觉、本体状态、历史融合
策略条件
   ↓ 动作生成与执行
新的接触
```

这里每一步都可能丢信息。好的表示不需要保留所有原始细节，但应保留当前任务用得上的差异。

## 1. 先区分触觉中的几种物理量

### 1.1 压阻阵列提供的是许多位置上的传感器响应

一个触觉感知单元通常称为 taxel，类似图像中的 pixel。压阻阵列输出可写成：

\[
r_t=[r_{t,1},\ldots,r_{t,N}].
\]

这里的 \(r_{t,i}\) 可能是电阻、ADC 值或厂商处理后的响应。它是否能写成压力 \(p_{t,i}\)，要看是否做过相应标定。

如果没有明确的单位与标定关系，把它称为“压力响应”或“归一化触觉读数”更准确。不能仅因数值随按压增大，就把它标成牛顿。

对于已经标定为压力、且每个单元有效面积 \(A_i\) 已知的阵列，可以在适用的接触假设下估算局部法向力：

\[
f_{n,i}\approx p_i A_i.
\]

若各单元位于同一平面且法向一致，求和可近似描述该面的法向载荷。对于弯曲、分布在不同手指上的传感器，还需要各自法向、坐标变换和传感器响应模型；不能把所有通道数值相加后直接称为物体所受合力。

### 1.2 三维力、六维力/力矩与压力图各有侧重

三维力传感器通常输出某个传感器坐标系中的：

\[
f_t=[f_x,f_y,f_z].
\]

六维 wrench 则额外包含三个力矩分量：

\[
w_t=[f_x,f_y,f_z,\tau_x,\tau_y,\tau_z].
\]

三维力提供方向信息，但单个合力向量通常不包含完整的接触分布。掌面阵列提供接触在空间上如何分布，却不能仅凭标量法向响应唯一恢复切向力。

例如，一个物体在掌面上接触面积相同、法向压力相近，却可能承受不同方向的切向作用。指尖三维力可以补充相关线索，但它测到的是该指尖处的受力，不能直接当成整个掌面的剪切场。

### 1.3 视触觉图像记录的是传感器表面的视觉变化

视触觉可能提供 RGB、marker 位移、形变图，或由重建算法得到的深度。图像亮暗、几何形变、力值之间需要具体传感器模型连接。

尤其要区分：

| 数据 | 可以直接表达什么 | 不能直接假定什么 |
| --- | --- | --- |
| 原始视触觉 RGB | 颜色、纹理与接触形变线索 | 每个像素已经对应物理力 |
| marker 位移场 | 跟踪点的图像位移 | 位移数值已经以牛顿计量 |
| 经标定的几何深度 | 约定坐标系下的几何量 | 深度本身就是压力 |
| 8-bit depth 可视化 | 一种灰度编码后的外观 | 灰度差 1 就对应固定米制深度差 |

[RDP 原文](https://arxiv.org/abs/2503.02881)将光学触觉特征与机器人力/力矩作为不同输入路线使用；它们能服务相似控制任务，但数据含义并不相同。读论文或接数据集时，应先确认原始信号，再确认 encoder。

## 2. 硬件配置决定输入形式

下面两种配置都可以研究触觉策略，但需要不同的数据入口：

| 可替换案例 | 实际输入 | 合理的第一版编码 |
| --- | --- | --- |
| A：掌面压阻＋指尖三维力 | 掌面标量阵列、各指尖力向量 | 掌面小 CNN＋指尖共享 MLP |
| B：掌面和指节压阻＋指尖视触觉 | 多区域标量阵列、各指尖图像 | 区域阵列编码＋指尖共享 CNN |

案例 A 中没有指节密集阵列，就不应给模型设计一个“指节压力图”输入；案例 B 的指尖图像也不应被默认为三维力。

更换硬件、mapping 或传感器固件时，应保存对应版本信息，例如 taxel 数量、通道到区域的映射、左右手、单位、图像编码与失效通道。这样，同样名为 `tactile` 的字段才不会在不同数据中代表完全不同的东西。

## 3. 把原始读数组织成可学习的空间输入

### 3.1 规则阵列：先用二维 CNN

如果掌面传感器本身是规则的 \(H_p\times W_p\) 网格，可以构造：

\[
X_t^{\rm palm}\in\mathbb R^{B\times C\times H_p\times W_p}.
\]

一个实用的三通道起点是：

1. 归一化压力响应；
2. 当前测量有效性；
3. 静态几何占位，即该网格位置是否真实存在传感器。

这三层区分了“没有 taxel”“taxel 当前坏了”和“taxel 正常且没有接触”。无效位置可以填固定值，但必须让 mask 与它一起进入编码器。

在此基础上，小 CNN 输出若干局部特征，再按掌面区域池化。对于第一版模型，不必立即使用大型视觉主干。

### 3.2 Numeric atlas：保留数值的二维排布

Atlas 可以理解为把各传感器区域排到一张约定的二维地图上。**地图承载的是数值与对应关系，不必先渲染成彩色热力图。**

彩色热力图适合人看，但 colormap 会增加无关的颜色变换，甚至受到绘图范围和压缩影响。直接存数值、mask 与 mapping 更容易保持可复现性。

Atlas 的邻接也需要解释。两个手指区域在画布上相邻，不意味着它们在真实手上贴在一起。可以给区域之间留间隔、分别编码后融合，或者通过明确的几何邻接建立交互。

### 3.3 不规则排布：把几何附到 taxel 特征上

对于不同 link 上分布不均匀的 taxel，可以组织：

\[
u_{t,i}=
[\bar r_{t,i},\dot{\bar r}_{t,i},v_{t,i},\Delta t_{t,i},
e_{\rm link(i)},p_i,n_i].
\]

其中 \(v\) 是有效性，\(\Delta t\) 是观测年龄，\(e_{\rm link}\) 是区域或 link 身份，\(p_i,n_i\) 是已标定的位置与法向。没有可靠几何标定时，可以先使用区域 ID，不必填入臆造的坐标。

共享 MLP、局部图网络或局部 attention 都可以读取这种输入。[3D-ViTac](https://arxiv.org/abs/2410.24091)提供了一个相关实例：在统一三维空间内保留视觉与触觉的空间关系，再接扩散策略。它支持“几何关系值得保留”这一设计方向，不意味着所有平台都必须采用同一种点云网络。

## 4. 坐标系决定“这里”和“这个方向”的含义

手指弯曲后，传感器还在原来的 link 上，但它相对于掌面的方向已经改变。若要比较不同手型下的触觉，必须提供关节状态，或显式使用正运动学更新几何。

设 \(\ell\) 为传感器所在 link，\(P\) 为手掌坐标系：

\[
\begin{aligned}
p_i^P &= R_{P\ell}(q_t)p_i^\ell+t_{P\ell}(q_t),\\
n_i^P &= R_{P\ell}(q_t)n_i^\ell.
\end{aligned}
\]

位置需要旋转和平移，法向只需要旋转。三维力向量同样只做旋转：

\[
f^P=R_{PS}(q_t)f^S.
\]

若处理六维 wrench，改变力矩参考原点时还会涉及力臂项，不能把六个数一律当作两个无关三维向量。

一种便于维护的输入方案是同时保留固定的局部身份，以及当前关节状态。需要跨区域几何融合时，再增加掌坐标中的位置和法向。双手系统还应明确左右手与共享基座坐标，不要仅凭图像左右翻转来推断物理方向。

## 5. 区域 tokens：在保留位置和控制计算量之间折中

几百个 taxel 不一定都要直接进入全局 attention。可以先局部编码，再生成少量区域 token：

```text
每个 taxel 的数值与有效性
            ↓ 局部 CNN / 共享 MLP / 局部图
局部接触特征
            ↓ 按物理区域池化
掌区 1、掌区 2、指尖 1、指尖 2……的 tokens
            ↓ 小型融合网络
当前触觉表示
```

区域池化可以组合均值、最大值或可学习 attention。只取均值可能掩盖一个很小的高压点，因此还可以保留峰值、接触比例和有效覆盖率作为补充。

对于规则平面阵列，在接触量足够、读数可比较时，可以计算压力加权中心：

\[
\bar p_t=
\frac{\sum_i v_{t,i}w_{t,i}p_i}
{\sum_i v_{t,i}w_{t,i}+\epsilon}.
\]

这里 \(w_i\) 必须是非负权重，并先扣除无接触基线、按传感器标定处理接触阈值。不要直接代入 z-score 标准化后含负数的输入，否则分母可能相互抵消。如果采用未经物理标定的响应，只能称为响应加权中心；若要解释为压力中心，应使用局部法向力作为权重，例如压力乘以 taxel 有效面积，并说明阵列的平面和坐标约定。

没有接触时，中心没有可靠意义，需要单独的有效标志。多个接触斑块的加权中心也不等于任何一个物体的中心。

**统计量适合作为补充，而不宜过早替代完整的空间编码。** 两个分离的接触点与一个中央接触点，可能具有相似均值和中心，却需要完全不同的动作。

## 6. 标定、归一化和时间同步属于模型设计

### 6.1 保留绝对幅值

可以用训练集拟合的固定统计量进行标准化：

\[
\bar r_{t,i}=\frac{r_{t,i}-\mu_i}{\max(\sigma_i,\epsilon)}.
\]

也可以使用固定量程缩放。关键是保持训练与部署的一致性，避免每帧独立缩放抹掉载荷变化。无效通道不参与统计拟合；若不同通道尚未物理标定，标准化也不会自动让它们具有相同力学含义。

原始数据应保留，以便重新标定。夹紧到固定范围可以限制异常值影响，但应记录饱和或裁剪标志，否则模型无法区分“刚达到上限”和“已经远超上限”。

### 6.2 当前值与变化率互补

变化率可以用相邻有效测量和真实时间差计算：

\[
\dot r_{t,i}\approx
\frac{r_{t,i}-r_{t-1,i}}{t_i-t_{i,\rm prev}}.
\]

它有助于表达接触建立、释放和迁移，但会放大噪声。两个样本相隔太久、其中一个无效或处于饱和状态时，变化率也应标为不可用。

压阻迟滞、零点漂移和加载速度都可能影响读数。应通过重复加载/卸载与静置测试了解这些现象，避免把传感器自身的历史效应误认成物体运动。神经网络可以学习补偿的一部分，但前提是数据覆盖了这些情况。

### 6.3 对齐“决策时已经收到”的信息

视觉、压力、指尖力和机器人状态通常不是同时到达。一个因果的起点是：在决策时刻读取各流最近一次已经到达的有效测量，并提供观测年龄。

离线记录中知道未来会来哪一帧，不代表线上可以提前使用它。居中平滑、使用未来样本的插值，以及事后补齐的物体位置，都需要检查是否会泄漏未来信息。

若在高频触觉降采样时提取均值、峰值或接触事件，统计窗口也只能覆盖当前及过去。频率应来自真实时间戳和链路测量，不能直接把文件的帧索引速率当成所有传感器的采样率。

## 7. Embedding、token 与条件描述的是不同层面

Embedding 是数值表示；token 强调它作为序列中的一个元素；条件描述它在生成模型中的作用。同一个向量可以同时是触觉 embedding、一个 tactile token，以及动作生成的条件。

设当前视觉、触觉和本体特征分别为 \(z_t^v,z_t^T,z_t^q\)，最简单的条件是：

\[
c_t=\operatorname{MLP}([z_t^v;z_t^T;z_t^q]).
\]

随后，扩散策略根据它生成动作：

\[
\epsilon_\theta(A_t^k,k,c_t).
\]

输入中 \(A_t^k\) 是带噪动作，\(k\) 是去噪步，\(c_t\) 是固定于这次动作采样的观测条件。触觉并不需要变成离散词表，才有资格影响生成。

常见的读取接口包括：

| 接口 | 计算形式 | 它做的事 |
| --- | --- | --- |
| 拼接与 MLP | \(c=F([z^v;z^T;z^q])\) | 合成统一条件向量 |
| FiLM | \(h'=\gamma(c)\odot h+\beta(c)\) | 用条件调节中间特征 |
| Cross-attention | 动作特征作 Q，观测 tokens 作 K/V | 从不同观测条目中读取信息 |

[DP 官方 U-Net](https://github.com/real-stanford/diffusion_policy/blob/main/diffusion_policy/model/diffusion/conditional_unet1d.py)有全局条件入口，并在条件残差块中使用特征调制；实际是否预测 scale 与 bias 由配置决定。这说明加入触觉可以先改变条件分支，不必重写整个动作生成器。

## 8. 一个小模型的完整输入示例

以案例 A 为例，下面给出可实现的第一版；\(B\) 为 batch size，\(J\) 为装有三维力传感器的指尖数：

```text
掌面压力 / validity / 几何占位 [B,3,H_p,W_p]
    → 小 CNN → 掌区特征 [B,R_p,64]

各指尖力 / validity / 观测年龄 / 指尖身份
    → 共享 MLP → 指尖特征 [B,J,64]

掌区与指尖特征
    → 区域融合 → 当前触觉 z_T [B,128]

图像 → 视觉编码器 → z_v
关节状态、腕部状态 → MLP → z_q

[z_T,z_v,z_q] → 条件 MLP → c [B,256]
                                      ↓
                              条件动作生成器
```

这里的 64、128、256 都只是起步维度。若使用案例 B，应把指尖力 MLP 换成符合真实图像格式的 CNN，并增加实际存在的压力区域；不要把两套配置的所有输入默认堆在一起。

需要历史时，在条件分支加入记忆模块，同时保留当前触觉直达策略的路径。这样，策略既能读取长期线索，也能及时响应眼前变化。其训练与运行方式见[下一篇](40_policy_memory_and_object_centric_tactile_state.md)。

## 9. 选择表示时的判断顺序

先确定任务依赖哪些差异：接触位置、绝对载荷、方向、短时变化，还是多物体归属。然后检查真实传感器能提供哪些证据，再选择空间表示和时间模块。

规则掌面阵列通常可以从小 CNN 开始；固定数量的三维力向量可以从 MLP 开始；跨 link 的不规则传感器在几何标定充分时可以增加几何特征。区域 token 为后续时序记忆保留了可区分的接触位置。

表示是否有效，最终要看它是否帮助后续决策。接触分类或重建做得好，可以说明 encoder 学到了一部分规律；要证明它改善了操作，还需要有效动作示范和独立闭环实验，见[实验设计篇](41_tactile_memory_experiment_design.md)。
